# 8086 Reflex Game

This is a simple reflex game written in 8086 Assembly using EMU8086.

## Features
- Random key generation (1-4)
- Reaction time measurement
- Score system
- Lives system
- Increasing difficulty
- Restart / Exit menu

## How to Run
1. Open the code in EMU8086
2. Compile and run
3. Press the correct key before time runs out

## Controls
- Press the shown number key
- 1 → Restart
- 2 → Exit
